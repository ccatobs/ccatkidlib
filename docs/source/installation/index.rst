Installation 
============

*ccatkidlib* depends on the following for data acquisition; no additional dependencies are required for analysis:

* **REQUIRED** -- *primecam_readout*
* **REQUIRED** -- *ocs*
* **RECOMMENDED** -- *rfsoc-streamer*

See :doc:`dependencies` for detailed information about each of the dependencies and any additional instructions for integration with *ccatkidlib*. 
After installing the dependencies, see :doc:`installation` for instructions on installing *ccatkidlib*.
