Dependencies
============

primecam_readout
----------------

*Primecam_readout* provides the FPGA firmware and low-level Python software for controlling Xilinx ZCU111 Radio Frequency System on a Chip (RFSoC) boards. 
Therefore, a fully functioning *primecam_readout* installation is required on the control computer as well as on each RFSoC board in order to use *ccatkidlib* for data acquisition.
